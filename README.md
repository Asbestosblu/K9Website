# K9NEXUS

A responsive React + Vite + TypeScript concept site for a welfare-first canine learning startup.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The early-access form is a front-end interaction demo and does not submit data to a backend. Hero and editorial photography load from Unsplash; Space Grotesk and DM Sans load from Google Fonts.
